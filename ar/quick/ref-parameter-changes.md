## كل التغييرات

| المجموعة | المعامل | قبل | بعد | الدليل | الغرض منه |

| الاتجاه | `AHRS_ORIENTATION` | 2 (Yaw90) | **0 (None)** | 03 | يخبر ArduPlane بطريقة تركيب Pixhawk. 0 = السهم متجه نحو المقدمة، وهو ما يطابق التركيب الفعلي. |

| المعايرة | `INS_ACC2OFFS_X/Y/Z, INS_ACC2SCAL_X/Y/Z` | قديمة / 1.0 | قيم جديدة | 03 | الشيء نفسه لمقياس التسارع الثاني. |

| `Q_FRAME_CLASS` | 7 | ثلاثية المراوح: 3 محركات رفع |
| `Q_TILT_ENABLE / Q_TILT_MASK` | 1 / 3 | المحركان 1 + 2 قابلان للإمالة |

| `Q_TILT_MAX / Q_TILT_YAW_ANGLE` | 70 / 10° | أقصى إمالة في أوضاع VTOL / مدى الإمالة للانعراج |
| `SERVO1/2_FUNCTION` | 4 Aileron | MAIN 1–2: الجنيحات |
| `SERVO3/4_FUNCTION` | 79 / 80 VTailLeft/Right | MAIN 3–4: الذيل على شكل V |
| `SERVO5/6/8_FUNCTION` | 33 / 34 / 36 Motor1/2/4 | MAIN 5، 6، 8: وحدات ESC |
| `SERVO7_FUNCTION` | 39 | يُسند تلقائيًا بواسطة هيكل Tri (اترك MAIN 7 فارغًا) |

## قيم تتغير من تلقاء نفسها

| المعامل | سبب تغيّره |
|---|---|
| `INS_GYROFFS_*, INS_GYR2OFFS_*, INS_GYR*_CALTEMP` | إزاحات الجيروسكوب، يُعاد قياسها تلقائيًا عند كل إقلاع للنظام. |
| `BARO1_GND_PRESS` | ضغط الهواء على الأرض، يُقاس عند كل إقلاع للنظام. |
| `STAT_*` | إحصائيات: عدد مرات الإقلاع، مدة التشغيل، مدة الطيران. |
| `BRD_SD_SLOWDOWN` | إعداد سرعة بطاقة SD تعدّله اللوحة. |

> 💡 بعد إعادة التشغيل، قد يعرض QGC نحو 1,276 فقط من أصل نحو 1,430 معاملًا. استخدم **Parameters → Tools → Refresh** قبل الحفظ أو المقارنة.
