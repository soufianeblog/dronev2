# VTOL Y3 · قوائم مهام سريعة

[English](../../quick/README.md) · [Français](../../fr/quick/README.md) · **العربية**



قوائم فحص بأسلوب "افعل هذا ثم ذاك" لإعداد VTOL Y3. قراءة كل واحدة منها تستغرق بضع دقائق.
هل تريد الأسباب ولقطات الشاشة والسجلات أيضًا؟ افتح **[الأدلة الكاملة في المتصفح](https://soufianeblog.github.io/dronev2/ar/)**.

## الطائرة

| | |
|---|---|
| هيكل الطائرة | VTOL ثلاثية المراوح بمراوح قابلة للإمالة: محركان أماميان قابلان للإمالة، محرك خلفي ثابت، جنيحات، ذيل على شكل V |
| وحدة التحكم في الطيران | Pixhawk 2.4.8 (هدف البرنامج الثابت `Pixhawk1`) يعمل بنظام **ArduPlane 4.7.2** (QuadPlane) |
| المحطة الأرضية | QGroundControl 5.1.5 على macOS |
| الراديو | FlySky i6X → جهاز الاستقبال iA10B → مشفّر PPM → مدخل **RC IN** في Pixhawk |
| GPS | M8N مع بوصلة |

## قواعد لكل قائمة مهام

- 🔌 **USB فقط:** بدون بطارية LiPo وبدون مراوح، ما لم تذكر القائمة خلاف ذلك.
- 💾 **نسخة احتياطية قبل وبعد:** *Parameters → Tools → Save to file…* داخل `backups/`.
- 🔄 **حدّث بعد كل إعادة تشغيل:** انتظر 30 ثانية، ثم *Parameters → Tools → Refresh*، قبل أن تغيّر أو تحفظ أي شيء. وإلا ستكون نحو 144 من إعدادات VTOL مفقودة من القائمة.
- 🧭 **أين توجد الأشياء في QGC 5.1.5:**
  - **صفحات الإعداد:** انقر أيقونة **Q** البنفسجية (أعلى اليسار) → **Vehicle Configuration**.
  - **شاشة الخريطة الرئيسية:** أيقونة **Q** → **Fly**.
  - **الرسائل:** أيقونة الرسائل في الشريط العلوي.
