# 06 · المخارج: توصيل السيرفوهات واختبارها (ثم المحركات)

[English](../../quick/06-outputs-servo-test.md) · [Français](../../fr/quick/06-outputs-servo-test.md) · **العربية**

[← 04](04-radio-modes-arming.md) · [الفهرس](README.md) · التالي: 07 ⏳ · [الدليل الكامل](https://soufianeblog.github.io/dronev2/ar/guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html)

**الهدف:** أن يكون كل سيرفو موصولًا بالمخرج الصحيح في Pixhawk ويتحرك في الاتجاه الصحيح. المحركات تأتي لاحقًا، **بدون مراوح**.
**ما تحتاجه:** إتمام [04](04-radio-modes-arming.md). **المراوح منزوعة** من المحركات الثلاثة. بطارية LiPo فقط عندما تطلب ذلك خطوةٌ ما.

## A. أين يُوصَل كل شيء

| مخرج Pixhawk | ما يُوصَل به |
|---|---|
| **<bdi>MAIN 1</bdi>** | سيرفو الجنيح الأيسر |
| **<bdi>MAIN 2</bdi>** | سيرفو الجنيح الأيمن |
| **<bdi>MAIN 3</bdi>** | سيرفو جناح الذيل الأيسر |
| **<bdi>MAIN 4</bdi>** | سيرفو جناح الذيل الأيمن |
| **<bdi>MAIN 5</bdi>** | ESC، المحرك الأمامي **الأيمن** (M1) |
| **<bdi>MAIN 6</bdi>** | ESC، المحرك الأمامي **الأيسر** (M2) |
| <bdi>MAIN 7</bdi> | **اتركه فارغًا** |
| **<bdi>MAIN 8</bdi>** | ESC، محرك الذيل (M4) |
| **<bdi>AUX 1</bdi>** | سيرفو الإمالة، المحرك الأمامي **الأيسر** |
| **<bdi>AUX 2</bdi>** | سيرفو الإمالة، المحرك الأمامي **الأيمن** |

اليسار/اليمين = كما تراهما وأنت جالس في الطائرة تنظر إلى الأمام. لا حاجة لإعادة التعيين: `SERVOn_FUNCTION` مطابق مسبقًا.

## B. توصيل السيرفوهات (Pixhawk مطفأ)

- [ ] **1.** افصل **USB** وبطارية **LiPo**.
- [ ] **2.** لكل قابس: **البرتقالي/الأصفر/الأبيض (الإشارة) في الأعلى**، الأحمر (+) في الوسط، **البني/الأسود (−) في الأسفل** بجوار قاعدة اللوحة.
- [ ] **3.** وصّل سيرفوهات الأسطح الأربعة (<bdi>MAIN 1–4</bdi>) وسيرفوي الإمالة (<bdi>AUX 1–2</bdi>) حسب الجدول.
- [ ] **4.** وصّل أسلاك ESC الثلاثة: **<bdi>MAIN 5</bdi>** الأمامي الأيمن، **<bdi>MAIN 6</bdi>** الأمامي الأيسر، **<bdi>MAIN 8</bdi>** الذيل. أبقِ السلك الأحمر فقط على <bdi>MAIN 8</bdi> (أخرِجه وثبّته بشريط لاصق في <bdi>MAIN 5</bdi> و<bdi>6</bdi>). المراوح منزوعة.
- [ ] **5.** 📸 التقط صورة لصف الدبابيس.

## C. حدود آمنة لسيرفوهات الإمالة

- [ ] **1.** وصّل USB، انتظر 30 ثانية ← **Q** ← **<bdi>Vehicle Configuration</bdi>** ← **<bdi>Parameters</bdi>** ← **<bdi>Tools</bdi>** ← **<bdi>Refresh</bdi>**.
- [ ] **2.** ابحث عن كل اسم ← انقر عليه ← اكتب القيمة ← **<bdi>Save</bdi>**:

  | المعامل | الحالي | اضبطه على (مؤقتًا) |
  |---|---|---|
  | `SERVO9_MIN` | 800 | **1100** |
  | `SERVO9_MAX` | 1940 | **1900** |
  | `SERVO10_MIN` | 700 | **1100** |
  | `SERVO10_MAX` | 2100 | **1900** |

  المراجعة 4: الأطراف النهائية في الجزء N (`SERVO9` 800–1900، `SERVO10` 800–2000).

## D. تغذية سكة السيرفو (5 V)

Pixhawk **لا** يغذّي دبابيس السيرفو من USB ولا من وحدة الطاقة. اختر أحد الخيارين:

- [ ] **A. منظم BEC لأحد ESC:** وصّل ESC الذيل بـ **<bdi>MAIN 8</bdi>**. يحتفظ ESC **واحد فقط** بسلكه الأحمر؛ أخرِج السلك الأحمر من القابسين الآخرين وثبّته للخلف بشريط لاصق.
- [ ] **B. جهد 5 V من PDB:** سلك من نقاط **5 V** في لوحة PDB إلى زوج + / − حر على السكة (مثلًا <bdi>MAIN 7</bdi>، مع ترك دبوس الإشارة فارغًا). ⚠️ **لا تستخدم 12 V أبدًا.**

## E. اختبار سيرفوهات الجناحين والذيل (<bdi>FBWA</bdi>)

- [ ] **1.** المراوح منزوعة. جهاز الإرسال قيد التشغيل، المفاتيح للأعلى، الخانق للأسفل.
- [ ] **2.** وصّل USB، ثم بطارية LiPo.
- [ ] **3.** اضغط على **زر الأمان** الأحمر (كابل منفصل، منفذ **<bdi>SWITCH</bdi>**) ثانيتين حتى يصبح ضوؤه **ثابتًا** (هذا لا يُسلّح شيئًا).
- [ ] **4.** **<bdi>SWC</bdi> للأسفل** (<bdi>FBWA</bdi>).
- [ ] **5.** **Q** ← **<bdi>Vehicle Configuration</bdi>** ← **<bdi>Servo Outputs</bdi>**: راقب عمود **<bdi>Position</bdi>**.
- [ ] **6.** حرّك العصي وتحقق ([الرسومات](ref-stick-controls.md)):

  | الحركة | ما يجب أن يحدث |
  |---|---|
  | العصا اليمنى ← لليمين | الجنيح الأيسر **للأسفل**، الجنيح الأيمن **للأعلى** |
  | العصا اليمنى ↓ (مسحوبة للخلف) | جناحا الذيل كلاهما **للأعلى** |
  | العصا اليسرى ← لليمين | جناح الذيل الأيمن **للأعلى**، جناح الذيل الأيسر **للأسفل** |

- [ ] **7.** الاتجاه خاطئ؟ **<bdi>Servo Outputs</bdi>** ← فعّل **<bdi>Reversed</bdi>** في ذلك الصف ← اختبر مجددًا.
- [ ] **8.** أمِل الطائرة بيدك: الجناح الأيمن للأسفل ← الجنيح الأيمن **للأسفل**، والجنيح الأيسر **للأعلى**. المقدمة للأسفل ← جناحا الذيل كلاهما **للأعلى**.

## F. اختبار سيرفوهات الإمالة

- [ ] **<bdi>SWC</bdi> في الوسط** (<bdi>QHOVER</bdi>) ← يتجه المحركان الأماميان **عموديًا للأعلى**.
- [ ] **<bdi>SWC</bdi> للأسفل** (<bdi>FBWA</bdi>) ← يميل كلاهما **للأمام** ببطء (~25°/ث).
- [ ] **<bdi>SWC</bdi> في الوسط** مجددًا ← يعودان للأعلى (أسرع، ~80°/ث).
- [ ] انتبه إلى أي **طنين** عند أحد الطرفين: سجّل أي محرك وأي طرف.

## G. المفاتيح والأوضاع ([الخطوة 6](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#switches)) ✅ أُنجزت 2026-10-18

- [ ] **1.** **Q** ← **<bdi>Vehicle Configuration</bdi>** ← **<bdi>Radio</bdi>** ← *<bdi>Channel Monitor</bdi>*: العصي 1–4، <bdi>SWA</bdi> 5، <bdi>SWC</bdi> 6.
- [ ] **2.** FlySky: اضغط مطولًا على **<bdi>OK</bdi>** ← **<bdi>Functions setup</bdi>** ← **<bdi>Aux. channels</bdi>** ← **<bdi>Channel 7</bdi>** = **<bdi>SwB</bdi>** ← اضغط مطولًا على **<bdi>CANCEL</bdi>**. الشريط 7 يتحرك الآن مع <bdi>SWB</bdi>.
- [ ] **3.** **<bdi>Flight Modes</bdi>** ← *<bdi>Switch Options</bdi>* ← **<bdi>Channel option 7</bdi>** = **<bdi>RTL</bdi>** (`RC7_OPTION` = 4). <bdi>SWB</bdi> للأسفل = العودة إلى نقطة الإقلاع.
- [ ] **4.** **<bdi>Parameters</bdi>** ← `Q_RTL_MODE` = **<bdi>QRTL Always</bdi>** (3): يعود كدرون ويهبط عموديًا.
- [ ] **5.** **<bdi>Flight Modes</bdi>** ← **<bdi>Flight Mode 1</bdi>** و**<bdi>2</bdi>** = **<bdi>QStabilize</bdi>** (17). كانت <bdi>QLand</bdi> (لا يمكن التسليح فيها).
- [ ] **6.** **<bdi>Parameters</bdi>** ← `ARMING_RUDDER` = **<bdi>ArmOrDisarm</bdi>** (2): العصا اليسرى ↓+→ لمدة 3 ث تسلّح، ↓+← لمدة 2 ث تنزع التسليح.
- [ ] **7.** **<bdi>Parameters</bdi>** ← **<bdi>Tools</bdi>** ← **<bdi>Refresh</bdi>** ← **<bdi>Tools</bdi>** ← **<bdi>Save to file</bdi>** ← `params_after-switches.params`.

النتيجة: **<bdi>SWA</bdi>** للأسفل = تسليح · **<bdi>SWB</bdi>** للأسفل = العودة إلى نقطة الإقلاع · **<bdi>SWC</bdi>** أعلى <bdi>QStabilize</bdi> / وسط <bdi>QHover</bdi> / أسفل <bdi>FBWA</bdi>.

## H. لماذا لم تكن المحركات تدور ([الخطوة 7](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#prearm))

يرفض Pixhawk التسليح ما دام أحد فحوص *<bdi>PreArm</bdi>* يفشل. اقرأ الرسائل في QGC (شاشة **<bdi>Fly</bdi>**، نص الشريط العلوي).

- [x] `Hardware safety switch` ← اضغط الزر الأحمر (منفذ **<bdi>SWITCH</bdi>**) 3 ث حتى يثبت ضوؤه. يُقفَل من جديد بعد كل إعادة تشغيل.
- [x] `QLand mode not armable` ← <bdi>Flight Mode 1/2 = QStabilize</bdi>.
- [x] `QRTL mode not armable` ← أبقِ **<bdi>SWB</bdi> للأعلى** للتسليح.
- [x] `RC calibrating` ← غادر صفحة **<bdi>Radio</bdi>**.
- [x] `Battery 1 low voltage failsafe` ← وصّل بطارية LiPo.
- [x] `Compass not calibrated` ← عويرت على الطاولة (الجزء I).
- [x] `Logging failed` ← بطاقة microSD مهيّأة بنظام FAT32 (الجزء I).
- [x] `AHRS: not using configured AHRS type` ← يحتاج تثبيت GPS في الخارج؛ على الطاولة: `ARMING_SKIPCHK` = 16 (الجزء I).
- صفير ESC أثناء عدم التسليح = طبيعي («في انتظار الخانق»).

## I. إزالة عوائق التسليح على الطاولة ([الخطوة 8](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#blockers)) ✅ أُنجزت 2026-10-18

- [ ] **1.** بطاقة microSD: هيّئها بنظام **<bdi>FAT32</bdi>** على الحاسوب (≤ 32 GB؛ الأكبر: <bdi>exFAT</bdi>)، وأعدها وPixhawk مطفأ ← تختفي `Logging failed`.
- [ ] **2.** **Q** ← **<bdi>Vehicle Configuration</bdi>** ← **<bdi>Sensors</bdi>** ← **<bdi>Compass</bdi>** ← **<bdi>OK</bdi>** ← أدر الطائرة ببطء في كل الاتجاهات حتى **<bdi>Completed</bdi>** ← **<bdi>Reboot Vehicle</bdi>** ← أبقها ساكنة 30 ث.
- [ ] **3.** شريط الجودة أصفر = مقبول على الطاولة. أعد المعايرة في الخارج بعيدًا عن المعادن للحصول على الأخضر قبل أول طيران.
- [ ] **4.** في الداخل فقط: **<bdi>Parameters</bdi>** ← `ARMING_SKIPCHK` ← فعّل **<bdi>INS</bdi>** فقط (16) ← **<bdi>Save</bdi>**. (`AHRS: not using configured AHRS type` = انتظار تثبيت GPS.)
- [ ] **5.** وصّل بطارية LiPo ← تختفي رسالة الجهد المنخفض.
- [ ] **6.** زر الأمان (منفذ **<bdi>SWITCH</bdi>**): وميض = مقفل، ثابت = مفتوح. اضغطه 3 ث. يُقفَل من جديد بعد كل إعادة تشغيل.
- [ ] **7.** يُظهر QGC **<bdi>Ready To Fly</bdi>**.

> ⚠️ **على الطاولة فقط:** أعد `ARMING_SKIPCHK` إلى **0** قبل أي طيران.

## J. معايرة ESC ([الخطوة 9](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#esc-cal)) ✅ أُنجزت 2026-10-18

لماذا: يتعلّم كل ESC أن 1000 µs = توقف و2000 µs = أقصى سرعة. منظمات ESC غير المعايَرة تدور وحدها أو تبدو معطّلة.

- [ ] **1.** البطارية **مفصولة**، USB فقط، **المراوح مفكوكة**.
- [ ] **2.** **<bdi>Parameters</bdi>** ← `Q_ESC_CAL` = **1** ← **<bdi>Save</bdi>**.
- [ ] **3.** **<bdi>Parameters</bdi>** ← `ARMING_SKIPCHK` = **400** (<bdi>INS 16 + Board voltage 128 + Battery level 256</bdi>) ← **<bdi>Save</bdi>**.
- [ ] **4.** <bdi>SWC</bdi> **للأعلى** (<bdi>QStabilize</bdi>). زر الأمان حتى يصبح **ثابتًا**. <bdi>SWA</bdi> **للأسفل** ← **<bdi>Armed</bdi>**.
- [ ] **5.** العصا اليسرى **للأعلى تمامًا**. وصّل البطارية ← **صفرتان** (حُفظ الحد الأقصى).
- [ ] **6.** خلال ثانيتين تقريبًا: العصا اليسرى **للأسفل تمامًا** ← **3 صفرات قصيرة + 1 طويلة** (حُفظ التوقف).
- [ ] **7.** <bdi>SWA</bdi> **للأعلى**. الاستعادة: `Q_ESC_CAL` = **0**، `ARMING_SKIPCHK` = **16**.

## K. شرح الأوضاع والإمالة ([الخطوة 10](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#modes))

| <bdi>SWC</bdi> | الوضع | يطير كـ | المحركان الأماميان |
|---|---|---|---|
| للأعلى | **<bdi>QStabilize</bdi>** | درون | 90° للأعلى |
| الوسط | **<bdi>QHover</bdi>** | درون | 90° للأعلى |
| للأسفل | **<bdi>FBWA</bdi>** | طائرة | يميلان للأمام |

- <bdi>FBWA</bdi> على الطاولة: يبدأ الانتقال إلى وضع الطائرة (`Transition started airspeed 0.0`) لكنه لا يكتمل أبدًا دون GPS/سرعة هواء. تتبع الإمالة الخانق (حتى `Q_TILT_MAX` 70°) ويبقى محرك الذيل يدور. طبيعي (الجزء P). `Q_ASSIST_SPEED` الآن **5** (كانت 10).
- أوضاع الدرون، مسلّح: 90° مع إمالات انعراج صغيرة حتى ±5° (`Q_TILT_YAW_ANGLE`، كانت ±10°، الجزء N). أكبر عند خانق منخفض (×2)، وأصغر عند خانق مرتفع (×0.5). غير مسلّح: ساكنان عند 90°. ضرورية للانعراج.
- [ ] اختبار باليد: مسلّح، <bdi>QStabilize</bdi>، خانق منخفض، المراوح مفكوكة. أدر المقدمة باليد ← يميل المحركان الأماميان في اتجاهين متعاكسين.

## L. العودة إلى نقطة الإقلاع بـ SWB ([الخطوة 11](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#swb))

- **<bdi>SWB</bdi> للأسفل** ← <bdi>QRTL</bdi> (`Q_RTL_MODE` = 3): يصعد إلى `Q_RTL_ALT` 20 m، يعود كدرون إلى نقطة التسليح، يهبط عموديًا، وينزع التسليح.
- **<bdi>SWB</bdi> للأعلى** ← تستعيد التحكم.
- يحتاج إلى تثبيت GPS (في الخارج). فقدان إشارة الراديو أمر منفصل: يهبط في مكانه (<bdi>QLand</bdi>، الجزء M).

## M. حماية فقدان الراديو عند التشغيل ([الخطوة 12](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#rc-failsafe))

ظهر: `Throttle failsafe on`، `RC Short/Long Failsafe: switched to QLand`، `Radio failsafe on`، `QLand mode not armable` = كان جهاز الإرسال **مطفأً**.

- [ ] **1.** شغّل جهاز الإرسال **أولًا** (المفاتيح للأعلى، الخانق للأسفل)، **ثم** صِل الطائرة.
- [ ] **2.** ضوء جهاز الاستقبال: **أحمر ثابت** = متصل، **وامض** = لا اتصال.
- [ ] **3.** في النهاية: افصل الطائرة **أولًا**، **ثم** أطفئ جهاز الإرسال.
- [ ] **4.** إن حدث ذلك: عاد الراديو ← `Throttle failsafe off` / `RC Long Failsafe Cleared` ← **<bdi>SWC</bdi> إلى الوسط** ثم **للأعلى** ← <bdi>QStabilize</bdi>.

## N. سيرفوهات الإمالة الأمامية ([الخطوة 13](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#tilt)) ✅ حُلَّت: كانت تعمل بالعكس

عُدِّلت سابقًا، محفوظة في [`params_after-tilt-changes.params`](../../backups/params_after-tilt-changes.params): `SERVO9_MAX` من 1940 إلى **1900**، `SERVO10_MIN` من 700 إلى **800**، `SERVO10_MAX` من 2100 إلى **2000**، `Q_TILT_YAW_ANGLE` من 10 إلى **5**، `Q_M_THST_HOVER` من 0.479 إلى **0.37**.

- ما يجب أن يفعله Pixhawk (شيفرة ArduPilot 4.7.2): <bdi>QStabilize</bdi>/<bdi>QHover</bdi> = الإمالتان **عموديتان**، فقط إمالة الانعراج تحرّكهما (±`Q_TILT_YAW_ANGLE`، حتى ×2 بخانق منخفض). <bdi>FBWA</bdi> على الطاولة = الانتقال لا يكتمل أبدًا؛ تتبع الإمالة الخانق حتى `Q_TILT_MAX` 70°.
- **السبب (22:40):** سيرفوا الإمالة كانا يعملان بالعكس. <bdi>QStabilize</bdi>: أمر «العمودي» (الصف 9 ≈ 1843، الصف 10 ≈ 852) لكن المحركين للأمام. <bdi>FBWA</bdi>: المحركان يرتفعان نحو العمودي مع الخانق.

- [x] **1.** **Q** ← **<bdi>Vehicle Configuration</bdi>** ← **<bdi>Servo Outputs</bdi>**.
- [x] **2.** الصف **9**: ألغِ تحديد **<bdi>Reversed</bdi>** (`SERVO9_REVERSED` من 1 إلى 0).
- [x] **3.** الصف **10**: حدّد **<bdi>Reversed</bdi>** (`SERVO10_REVERSED` من 0 إلى 1).
- [x] **4.** تحقّق: <bdi>SWC</bdi> **للأعلى** و**الوسط** = المحركان مستقيمان، <bdi>SWC</bdi> **للأسفل** = للأمام. ✅ مؤكَّد.
- [ ] **5.** اختياري: ضبط دقيق للطرفين العمودي والأمامي (~10 µs ≈ 1°).
- [ ] **6.** **<bdi>Parameters</bdi>** ← **<bdi>Tools</bdi>** ← **<bdi>Refresh</bdi>** ← **<bdi>Tools</bdi>** ← **<bdi>Save to file</bdi>** ← نسخة احتياطية جديدة.

أُعيدت معاملات الانعراج إلى قيم ArduPilot الافتراضية (القديمة مرتفعة جدًا)، محفوظة في [`params_now.params`](../../backups/params_now.params): `Q_A_RAT_YAW_P` من 1.2 إلى **0.18**، `Q_A_RAT_YAW_I` من 0.6 إلى **0.018**، `Q_A_RAT_YAW_D` من 0.15 إلى **0**، و FF يبقى 0.1. الضبط الدقيق لاحقًا من سجلات الطيران.

💾 النسخ الاحتياطية: [`params_now.params`](../../backups/params_now.params) (انعراج افتراضي، جيروسكوب صالح) ← [`params_latest1.params`](../../backups/params_latest1.params) (فيها خانات <bdi>Manual</bdi>، `Q_ASSIST_SPEED` 5) ← [`params_latest2.params`](../../backups/params_latest2.params) (الخانات مصحّحة) = **الأحدث**. عكس الإمالة ليس في نسخة احتياطية بعد.

## P. شرح سلوكيات اختبار الطاولة ([الخطوة 15](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#desk))

| ما تراه | السبب ← ما يجب فعله |
|---|---|
| a. مسلّح على الطاولة، محرك مرتفع وآخر شبه متوقف (الصفوف 5/6/8 = 1835/1150/1664) | يحاول Pixhawk موازنة طائرة لا تتحرك. طبيعي. قيّم المحركات واحدًا تلو الآخر لاحقًا (اختبار المحركات). |
| b. <bdi>SWA</bdi> للأعلى أصلًا ولا يفعل شيئًا | سُلِّحت بالعصا اليسرى (`ARMING_RUDDER` = 2). <bdi>SWA</bdi> يعمل فقط عند قلبه: للأسفل ثم للأعلى. المخطط: `ARMING_RUDDER` ← **0** (<bdi>SWA</bdi> فقط)، قرارك. |
| c. محرك يرتعش/يدور ببطء بعد نزع التسليح | غير مسلّح = 1000 µs «توقف»، وقد يرتعش ESC. المخطط: `Q_M_SAFE_DISARM` ← **1** (لا إشارة؛ قد يصفر ESC، غير ضار؛ السيرفوهات لا تتأثر). معلّق. |
| d. محرك الذيل يدور في <bdi>FBWA</bdi> على الطاولة | الانتقال لا يكتمل إلا فوق أدنى سرعة هواء (GPS في الخارج). يتوقف في الطيران الحقيقي. `Q_ASSIST_SPEED` من 10 إلى **5**. فحص: انزع التسليح في وضع Q، حوّل إلى <bdi>FBWA</bdi> دون تسليح، سلّح في <bdi>FBWA</bdi> ← يجب أن يبقى محرك الذيل متوقفًا. |
| e. إزاحات الجيروسكوب 0 في نسخة احتياطية | تحرّكت الطائرة عند بدء التشغيل. أبقِها ساكنة ~15 ث حتى **<bdi>ArduPilot Ready</bdi>**. |
| f. `Q_M_THST_HOVER` تتغير (0.32 ← 0.57 ← 0.51) | يتعلّمها على الطاولة. اضبطها ≈ **0.37** قبل أول تحويم مباشرة. |

## Q. ما تبقّى

- [ ] حفظ نسخة احتياطية جديدة مع إصلاح الإمالة (الجزء N)
- [ ] اختياري: ضبط دقيق لأطراف الإمالة
- [ ] فحص على الطاولة: التسليح في <bdi>FBWA</bdi> ← محرك الذيل متوقف (الجزء P d)
- [ ] قرار `ARMING_RUDDER` = 0 (<bdi>SWA</bdi> فقط)
- [ ] `Q_M_SAFE_DISARM` = 1
- [ ] اختبار المحركات واحدًا تلو الآخر (بدون مراوح)
- [ ] اتجاه دوران كل محرك
- [ ] إعادة البوصلة في الخارج للحصول على الأخضر
- [ ] فحص <bdi>SWB</bdi> في الخارج: وضع الطيران يُظهر <bdi>QRTL</bdi>
- [ ] `ARMING_SKIPCHK` = 0 قبل أي طيران
- [x] صُحِّح اتجاه الإمالة (الصف 9 دون <bdi>Reversed</bdi>، الصف 10 مع <bdi>Reversed</bdi>)
- [x] صُحِّحت خانات أوضاع الطيران ← `params_latest2.params`
- [x] معاملات الانعراج افتراضية ← `params_now.params`

## R. قائمة الفحص قبل الطيران ([التفاصيل](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#preflight))

- [ ] `ARMING_SKIPCHK` أُعيد إلى **0**
- [ ] `Q_M_THST_HOVER` ≈ **0.37** قبل أول تحويم (يتعلّمه Pixhawk من جديد)
- [ ] `Q_ASSIST_SPEED` = **5**
- [ ] الإمالة: <bdi>SWC</bdi> للأعلى = مستقيمان، <bdi>SWC</bdi> للأسفل = للأمام
- [ ] الطائرة ساكنة ~15 ث بعد التشغيل (**<bdi>ArduPilot Ready</bdi>**)
- [ ] أُعيدت البوصلة في الخارج، **أخضر**
- [ ] جهاز الإرسال **أولًا**، ثم الطائرة
- [ ] زر الأمان **ثابت الضوء**
- [ ] المراوح على المحركات الصحيحة
- [ ] اختُبر <bdi>SWB</bdi> في الخارج (يظهر <bdi>QRTL</bdi>)

## ✅ يكتمل عندما

- يتحرك كل سطح في الاتجاه الصحيح في وضع <bdi>FBWA</bdi>.
- تتجه سيرفوهات الإمالة للأعلى في <bdi>QHOVER</bdi> وللأمام في <bdi>FBWA</bdi>، بدون طنين.
- يتسلّح Pixhawk وتدور المحركات الثلاثة معًا (بدون مراوح).
- أرسلت: صورة صف الدبابيس، قوابس ESC بثلاثة أسلاك أم بسلكين، خيار السكة A أو B، النتائج.

## المشاكل

| ما تراه | ما يجب فعله |
|---|---|
| لا شيء يتحرك، لكن قيم <bdi>Position</bdi> تتغير | لا يوجد 5 V على السكة. راجع الجزء D. |
| قيم <bdi>Position</bdi> لا تتغير | ضوء زر الأمان ليس ثابتًا. اضغط عليه مطولًا مجددًا. |
| سطح يتحرك في الاتجاه الخاطئ | **<bdi>Servo Outputs</bdi>** ← فعّل **<bdi>Reversed</bdi>** في ذلك الصف |
| سيرفو إمالة يطنّ عند أحد الطرفين | إنه يصطدم بحدٍّ ميكانيكي. اترك الحدود على 1100–1900 وأخبرني أي محرك وأي طرف. |
| سيرفو يرتعش أو يقفز | القابس مقلوب؟ يجب أن تكون الإشارة (البرتقالي/الأصفر) في الأعلى. |
| السيرفوهات تُعيد التشغيل أو تضعف عند تحركها معًا | مصدر طاقة السكة ضعيف. استخدم منظم UBEC بجهد 5–6 V وتيار 3 A أو أكثر. |
| الخانق لا يفعل شيئًا | Pixhawk غير مسلّح. اقرأ رسالة <bdi>PreArm</bdi> (الجزء H). |
| `QRTL mode not armable` | <bdi>SWB</bdi> للأسفل. ارفعه للأعلى. |
| `Logging failed` | هيّئ بطاقة microSD بنظام FAT32 (الجزء I). |
| `AHRS: not using configured AHRS type` | في الخارج: انتظر تثبيت GPS. على الطاولة: `ARMING_SKIPCHK` = 16 (الجزء I). |
| المحركات تدور وحدها أو أحدها يبدو معطّلًا | معايرة ESC (الجزء J). |
| الإمالة تتحرك / محرك الذيل يدور في <bdi>FBWA</bdi> على الطاولة | الانتقال لا يكتمل على الطاولة، طبيعي (الجزآن K وP). |
| المحركان الأماميان يتمايلان في وضع الدرون وهو مسلّح | إمالة الانعراج، طبيعي (الجزء K). |
| `Radio failsafe on`، `QLand mode not armable` عند التشغيل | كان جهاز الإرسال مطفأً. شغّله أولًا، ثم <bdi>SWC</bdi> الوسط ← الأعلى (الجزء M). |
| المحركان للأمام في <bdi>QStabilize</bdi> ويرتفعان في <bdi>FBWA</bdi> | سيرفوا الإمالة بالعكس: اعكس **<bdi>Reversed</bdi>** في الصفين 9 و10 (الجزء N). |
| محرك مرتفع وآخر شبه متوقف، مسلّح على الطاولة | موازنة طبيعية (الجزء P). |
| <bdi>SWA</bdi> للأعلى لا ينزع التسليح | التسليح كان بالعصا: اقلب <bdi>SWA</bdi> للأسفل ثم للأعلى (الجزء P). |
