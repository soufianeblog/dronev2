# 06 · المخارج: توصيل السيرفوهات واختبارها (ثم المحركات)

[English](../../quick/06-outputs-servo-test.md) · [Français](../../fr/quick/06-outputs-servo-test.md) · **العربية**

[← 04](04-radio-modes-arming.md) · [الفهرس](README.md) · التالي: 07 ⏳ · [الدليل الكامل](https://soufianeblog.github.io/dronev2/ar/guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html)

**الهدف:** كل سيرفو وكل ESC على المخرج الصحيح، المفاتيح مضبوطة، وكل وضع مُختبَر على الطاولة.
**تحتاج إلى:** إنهاء [04](04-radio-modes-arming.md). **المراوح منزوعة** من المحركات الثلاثة. LiPo فقط عندما تطلب ذلك خطوةٌ ما.

**الحالة الآن:** ✅ كل المخارج تتحرك · ✅ المفاتيح مضبوطة · ✅ يتسلّح على الطاولة · ✅ منظمات ESC معايَرة · ✅ الإمالة صحيحة في الأوضاع الثلاثة. ⏳ المحرك الخلفي يستمر في الدوران في FBWA على الطاولة (قيد البحث) · اختبار كل محرك على حدة · اتجاهات الدوران · البوصلة مجددًا في الخارج · اختبار SWB في الخارج.
💾 أحدث نسخة احتياطية: [`params_latest2.params`](../../backups/params_latest2.params). تصحيح الإمالة (`SERVO9_REVERSED` 0، `SERVO10_REVERSED` 1) ليس فيها بعد: احفظ نسخة جديدة.

## أين يُوصَل كل شيء

| المخرج | ما يُوصَل | المدى (µs) | Reversed |
|---|---|---|---|
| **MAIN 1** | سيرفو الجنيح الأيسر | 1100–1900 | لا |
| **MAIN 2** | سيرفو الجنيح الأيمن | 1000–2000 | لا |
| **MAIN 3** | سيرفو جناح الذيل الأيسر | 1000–2000 | لا |
| **MAIN 4** | سيرفو جناح الذيل الأيمن | 1000–2000 | لا |
| **MAIN 5** | ESC المحرك الأمامي **الأيمن** (M1) | 1000–2000 | لا |
| **MAIN 6** | ESC المحرك الأمامي **الأيسر** (M2) | 1000–2000 | لا |
| MAIN 7 | **اتركه فارغًا** | | |
| **MAIN 8** | ESC المحرك الخلفي (M4) | 1000–2000 | لا |
| **AUX 1** | سيرفو الإمالة الأمامي **الأيسر** | **800–1900** | **لا** |
| **AUX 2** | سيرفو الإمالة الأمامي **الأيمن** | **800–2000** | **نعم** |

اليسار/اليمين = وأنت جالس في الطائرة تنظر إلى الأمام.

## A. التوصيل ([التفاصيل](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#wiring))

- [ ] **1.** افصل **USB** و**LiPo**.
- [ ] **2.** كل قابس: **الإشارة (برتقالي/أصفر) في الأعلى**، الأحمر في الوسط، **البني/الأسود في الأسفل**.
- [ ] **3.** وصّل كل شيء كما في الجدول.
- [ ] **4.** السلك الأحمر لـ ESC فقط على **MAIN 8** (الخلفي). اسحبه من قابسي MAIN 5 و6 وغطّه بشريط.
- [ ] **5.** طاقة سكة السيرفو: السلك الأحمر لـ ESC الخلفي، **أو** **5 V** من لوحة PDB إلى زوج +/− حر. ⚠️ **لا 12 V أبدًا.**

## B. جهاز الإرسال والمفاتيح ([التفاصيل](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#switches))

| أداة التحكم | تفعل |
|---|---|
| **SWA** | أسفل = تسليح · أعلى = فك التسليح (فقط عند قلبه) |
| **SWB** | أسفل = العودة إلى نقطة الإقلاع كدرون (QRTL) · أعلى = الرجوع إلى وضع SWC |
| **SWC** | أعلى = **QStabilize** (درون، خانق مباشر) · وسط = **QHover** (درون، يحافظ على الارتفاع) · أسفل = **FBWA** (طائرة مع شبكة أمان) |
| العصا اليسرى ↓+→ 3 ث / ↓+← 2 ث | تسليح / فك التسليح |

- [ ] **1.** FlySky: اضغط مطولًا على **OK** ← **Functions setup** ← **Aux. channels** ← **Channel 7** = **SwB** ← اضغط مطولًا على **CANCEL**.
- [ ] **2.** **Q** ← **Vehicle Configuration** ← **Radio** ← *Channel Monitor*: الشريط 7 يتحرك مع SWB. غادر الصفحة.
- [ ] **3.** **Q** ← **Vehicle Configuration** ← **Flight Modes**: الخانات 1–2 **QStabilize**، 3–4 **QHover**، 5–6 **FBWA**. لا Manual ولا QLand.
- [ ] **4.** الصفحة نفسها ← *Switch Options* ← **Channel option 7** = **RTL**.

## C. إعدادات يجب التحقق منها ([التفاصيل](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#settings))

**Q** ← **Vehicle Configuration** ← **Parameters** (انتظر 30 ث بعد التشغيل، **Tools** ← **Refresh**). ابحث ← انقر ← اكتب ← **Save**.

| المعامل | القيمة | المعنى |
|---|---|---|
| `RC7_OPTION` | 4 | SWB = العودة إلى نقطة الإقلاع |
| `Q_RTL_MODE` | 3 | العودة كدرون |
| `FLTMODE1`…`6` | 17، 17، 18، 18، 5، 5 | SWC أعلى / وسط / أسفل |
| `ARMING_RUDDER` | 2 | التسليح بالعصا مفعّل |
| `ARMING_SKIPCHK` | 16 | تخطي فحص GPS في الداخل. **0 قبل الطيران** |
| `Q_ESC_CAL` | 0 | عادي (1 فقط لمعايرة ESC) |
| `Q_TILT_YAW_ANGLE` | 5 | إمالة تدوير المقدمة (±°) |
| `Q_A_RAT_YAW_P` / `I` / `D` | 0.18 / 0.018 / 0 | معاملات تدوير المقدمة، افتراضيات ArduPilot |
| `Q_ASSIST_SPEED` | 5 | محركات الدرون تساعد تحت هذه السرعة الهوائية (m/s) |
| `SERVO9_MIN` / `MAX` / `REVERSED` | 800 / 1900 / **0** | إمالة الأمامي الأيسر |
| `SERVO10_MIN` / `MAX` / `REVERSED` | 800 / 2000 / **1** | إمالة الأمامي الأيمن |
| `Q_M_THST_HOVER` | متعلَّم (0.51) | خانق التحويم. ≈ **0.37** قبل أول تحويم |

- [ ] كل القيم مطابقة.

## D. المعايرات ([التفاصيل](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#blockers))

- [ ] **1.** microSD: هيّئها **FAT32** (≤ 32 GB؛ الأكبر: exFAT)، وأدخلها وPixhawk مطفأ.
- [ ] **2.** **Q** ← **Vehicle Configuration** ← **Sensors** ← **Compass** ← **OK** ← أدِر الطائرة في كل الاتجاهات حتى **Completed** ← **Parameters** ← **Tools** ← **Reboot Vehicle**. أصفر = يكفي للطاولة؛ أعِدها في الخارج للأخضر.
- [ ] **3.** بعد كل تشغيل: ثبات **15 ث** (حتى **ArduPilot Ready**).
- [ ] **4.** معايرة ESC ([التفاصيل](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#esc-cal)): البطارية مفصولة، USB فقط، بدون مراوح ← `Q_ESC_CAL` = **1**، `ARMING_SKIPCHK` = **400** ← SWC أعلى، زر الأمان ثابت، SWA أسفل (**Armed**) ← العصا اليسرى **للأعلى تمامًا** ← وصّل البطارية (**صفرتان**) ← خلال 2 ث العصا **للأسفل تمامًا** (**3 قصيرة + 1 طويلة**) ← SWA أعلى ← `Q_ESC_CAL` = **0**، `ARMING_SKIPCHK` = **16**.

## E. قائمة التسليح ([التفاصيل](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#arming))

- [ ] **1.** جهاز الإرسال **أولًا** (المفاتيح للأعلى، الخانق للأسفل). ضوء المستقبل أحمر ثابت.
- [ ] **2.** وصّل الطائرة. ثبات **15 ث**.
- [ ] **3.** زر الأمان (المنفذ **SWITCH**): اضغطه **3 ث** حتى يصبح **ثابتًا** (وامض = مقفل؛ يُقفل من جديد بعد كل إعادة تشغيل).
- [ ] **4.** يعرض QGC **Ready To Fly**. SWB أعلى.
- [ ] **5.** SWA **أسفل** ← **Armed**.
- [ ] **6.** النهاية: SWA أعلى، افصل الطائرة أولًا، ثم أطفئ جهاز الإرسال.

## F. اختبار كل وضع، بدون مراوح ([التفاصيل](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#modes))

| SWC | الشريط العلوي | المحركان الأماميان | الخانق |
|---|---|---|---|
| أعلى | QStabilize | للأعلى تمامًا | مباشر |
| وسط | QHover | للأعلى تمامًا | يحافظ على الارتفاع |
| أسفل | FBWA | للأمام | على الطاولة: الإمالة تتبع الخانق (حتى 70°) |

- [ ] **1.** الصفوف الثلاثة صحيحة ✅. الإمالة بالعكس؟ **Servo Outputs** ← اقلب **Reversed** في الصفين 9 و10 (النهائي: 9 غير محدد، 10 محدد).
- [ ] **2.** FBWA: العصا اليمنى ← لليمين = الجنيح الأيسر للأسفل، الأيمن للأعلى. العصا اليمنى للخلف = جناحا الذيل للأعلى. العصا اليسرى ← لليمين = جناح الذيل الأيمن للأعلى، الأيسر للأسفل.
- [ ] **3.** سطح في الاتجاه الخاطئ؟ **Servo Outputs** ← حدد **Reversed** في صفّه.
- [ ] **4.** صفوف Servo Outputs: 5 و6 و8 = المحركات؛ 9 و10 = الإمالة. تحقق من المحركين بعينيك: للأعلى في أوضاع Q، وللأمام في FBWA.

## G. طبيعي على الطاولة ([التفاصيل](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#desk))

| ما تراه | السبب |
|---|---|
| مسلّح: محرك سريع وآخر شبه متوقف | موازنة طائرة لا تستطيع الحركة. طبيعي |
| المحركان الأماميان يميلان أكثر عند خانق منخفض | إمالة المقدمة ×2 عند خانق منخفض. طبيعي |
| SWA المرفوع أصلًا لا يفعل شيئًا | سُلِّح بالعصا. اقلب SWA للأسفل ثم للأعلى |
| محرك يرتعش بعد فك التسليح | ما زال يُرسَل 1000 µs «توقف». خيار: `Q_M_SAFE_DISARM` = 1 (معلّق) |
| المحرك الخلفي يدور في FBWA | الانتقال لا يكتمل في الداخل. ⏳ قيد البحث |
| `Q_M_THST_HOVER` يتغير | يُتعلَّم على الطاولة. ≈ 0.37 قبل أول تحويم |
| منظمات ESC تصفر | في انتظار الخانق. طبيعي |

## H. قائمة الفحص قبل الطيران ([التفاصيل](../guides/guide-06_2026-10-18_0210_outputs-and-servo-test.html#preflight))

- [ ] `ARMING_SKIPCHK` أُعيد إلى **0**
- [ ] `Q_M_THST_HOVER` ≈ **0.37**
- [ ] `Q_ASSIST_SPEED` = **5**
- [ ] نسخة احتياطية جديدة فيها تصحيح الإمالة
- [ ] الإمالة: SWC أعلى = للأعلى تمامًا، SWC أسفل = للأمام
- [ ] البوصلة أُعيدت في الخارج، **أخضر**
- [ ] جهاز الإرسال **أولًا**، ثم الطائرة
- [ ] الطائرة ثابتة ~15 ث (**ArduPilot Ready**)
- [ ] زر الأمان **ثابت**
- [ ] المراوح على المحركات الصحيحة
- [ ] اختُبر SWB في الخارج (ظهر QRTL)

## ✅ ينتهي عندما

- كل سطح يتحرك في الاتجاه الصحيح في FBWA.
- الإمالة للأعلى في QStabilize/QHover، وللأمام في FBWA.
- يتسلّح Pixhawk وكل محرك يدور في الاتجاه الصحيح (بدون مراوح).

## المشاكل

| ما تراه | افعل هذا |
|---|---|
| لا شيء يتحرك | لا 5 V على السكة (الجزء A) أو زر الأمان غير ثابت |
| سيرفو يرتعش | القابس مقلوب: الإشارة في الأعلى |
| الخانق لا يفعل شيئًا | غير مسلّح: اقرأ رسالة PreArm (شاشة **Fly**، الشريط العلوي) |
| `Hardware safety switch` | اضغط زر الأمان 3 ث |
| `QLand mode not armable` | الخانة 1/2 ليست QStabilize، أو حماية فقدان الراديو: SWC وسط ← أعلى |
| `QRTL mode not armable` | SWB أعلى |
| `RC calibrating` | غادر صفحة Radio |
| `Radio failsafe on` / `Throttle failsafe on` | جهاز الإرسال أولًا، ثم SWC وسط ← أعلى |
| `Battery 1 low voltage failsafe` | وصّل بطارية LiPo مشحونة |
| `Compass not calibrated` | الجزء D الخطوة 2 |
| `AHRS: not using configured AHRS type` | في الخارج: انتظر GPS. في الداخل: `ARMING_SKIPCHK` = 16 |
| `Logging failed` | هيّئ بطاقة microSD (الجزء D) |
| `Board (4.2v) out of range` | USB فقط: وصّل LiPo |
| المحركات تدور وحدها / أحدها يبدو معطلًا | معايرة ESC (الجزء D) |
| المحركان للأمام في QStabilize ويرتفعان في FBWA | اقلب **Reversed** في الصفين 9 و10 |
| وضع الطيران يعرض Manual | صحّح خانات Flight Mode (الجزء B) |
