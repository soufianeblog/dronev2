Parameter changes: before → after

Every ArduPlane parameter changed on the VTOL Y3 so far, with the old value, the new value and what it is for.

Compared: backups/params_after-guide02_4.7.2.params (the old setup, right after the firmware update) → backups/params_after-guide04.params (now). Bold = changed value. "Guide" = where it was changed.
