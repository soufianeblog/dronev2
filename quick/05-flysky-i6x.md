# 05 · FlySky i6X transmitter setup

Keys: **hold OK** = menu · **UP/DOWN** = move or change · **short OK** = open / next field · **CANCEL** = back · **hold CANCEL** = save.
Power on with all switches **up** and throttle **down**.

| # | Path (from the home screen) | Set / check |
|---|---|---|
| 1 | Home screen | TX + RX battery bars, `SigS1: 10` = linked |
| 2 | System setup → Type select | **Airplane** |
| 3 | System setup → Sticks mode | **2** |
| 4 | System setup → Aux switches | all **On**, Ch **10** |
| 5 | Functions setup → V Tail / Elevon / Mixes | all **Off** (the Pixhawk mixes) |
| 6 | Functions setup → Throttle hold | **Off** |
| 7 | Functions setup → Throttle curve | 0 / 25 / 50 / 75 / 100 |
| 8 | Functions setup → Dual rate/exp. | Ch1, 2, 4: Rate **100**, Exp **0** |
| 9 | Functions setup → Assign switches | all **None** |
| 10 | Functions setup → Reverse | all **Nor** |
| 11 | Functions setup → End points | all **100% / 100%** |
| 12 | Functions setup → Subtrim | all **0** |
| 13 | Home screen trims (4 rockers) | centred (high beep) |
| 14 | Functions setup → Aux. channels | Ch5 = **SwA**, Ch6 = **SwC** |
| 15 | System setup → RX setup → Output mode | **PWM** (with PPM encoder) · Serial: i-BUS |
| 16 | Functions setup → Display | each stick or switch moves only its own bar |

On list screens, **short OK = next channel** and **UP/DOWN = change the value**. ⚠️ Never open **RX setup → RF standard** (it can break the link).
